# Jason Keen

**Independent Researcher | OSINT | Financial Intelligence | Geopolitical Risk**

I use public sources and Python modeling to study how geopolitical events, financial networks, and market shocks create risk. My work connects open-source intelligence (OSINT) with scenario analysis, quantitative research, and clear reporting.

My research covers sanctions and ownership networks, maritime chokepoints, energy markets, equity risk, and strategic security questions. I build tools that make sources, assumptions, and uncertainty easier to inspect.

## Research standards

The standards guiding my work are:

- **Source transparency:** distinguish public evidence, analyst assumptions, and synthetic demonstrations; document sources and data dates.
- **Reproducibility:** record configurations, random seeds, and versioned inputs so results can be checked.
- **Validation:** use tests, sensitivity analysis, and appropriate backtesting; disclose gaps and separate software correctness from predictive performance.
- **Uncertainty:** report conditional results and limitations without treating scenario probabilities as observed facts.
- **Baseline preservation:** keep frozen research artifacts intact and review changes before promoting a new model version.

Validation maturity differs by project. Each repository's documentation and open review items define its current scope and limitations.

**Maritime version note:** the linked public repository identifies its release as v0.6.0. The separately audited v0.6.3 research package requires provenance and version reconciliation before it can be represented as the same public release.
